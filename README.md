## Tecnologias utilizadas

| Tecnologia | Uso no projeto |
|---|---|
| HTML5 | Estrutura e conteúdo semântico da página |
| CSS3 | Layout, cores, responsividade e animações |
| JavaScript | Menu para celular, destaque do menu ao rolar e animações de entrada |

## Destaques do projeto

- Layout responsivo, que se adapta a computador, tablet e celular.
- Menu de navegação com destaque automático da seção atual.
- Animações suaves ao rolar a página, que respeitam a preferência de movimento reduzido do usuário.
- Paleta de cores pensada para unir tecnologia e natureza.
- Publicado gratuitamente com o GitHub Pages.

## Como executar localmente

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/Isabellycristina7/portfolio.git
   ```
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador. Se preferir, use a extensão **Live Server** para atualizar a página automaticamente.
